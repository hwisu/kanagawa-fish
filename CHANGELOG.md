## [1.0.0] - 2024-02-04

### Added
- Initial release of Kanagawa Fish theme
- Dark theme (Wave) based on kanagawa.nvim color palette
- Light theme (Lotus) variant for light terminal backgrounds
- Full syntax highlighting support for Fish shell
- Completion pager colors
- Prompt colors (cwd, user, host)
- Fisher package manager support
